# 3D 圣诞树 🎄

用 Three.js 做的粒子圣诞树，纯前端单页，打开就能看。

## 效果

- 16000 个粒子螺旋上升，构成圆锥形树身，颜色从深绿渐变到亮绿
- 150 颗彩色小灯泡分成 5 组，各自按不同节奏呼吸闪烁
- 树顶一颗会脉动的金色星星，缓慢自转
- 1400 片雪花从夜空飘落，带轻微横向漂移
- 地面一圈冷蓝色光晕
- 相机自动环绕，也可以用鼠标拖动查看任意角度、滚轮拉近拉远

## 运行

直接双击 `index.html` 用浏览器打开即可，不需要装任何东西。

如果想通过本地服务器访问（部分浏览器对本地文件的限制更宽）：

```bash
python -m http.server 8000
```

然后打开 http://localhost:8000

## 交互

| 操作 | 效果 |
|---|---|
| 按住拖动 | 旋转视角 |
| 滚轮 | 拉近 / 拉远 |
| 松手 2 秒后 | 自动恢复环绕 |

## 技术说明

- `three.min.js` 是 Three.js r150 的本地副本，**不依赖 CDN**，断网也能打开
- 粒子的圆润光晕来自 canvas 径向渐变生成的贴图，而不是默认的方块点
- 树的形状用参数方程生成：高度 `t` 从 0 到 1，半径按 `(1-t)` 收缩，同时角度按 `t` 螺旋推进
- 树身使用加法混合（AdditiveBlending）让粒子叠加处自然发光，配合深色背景形成光感
